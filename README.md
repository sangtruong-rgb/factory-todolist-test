# Todolist

A small todo list web app, used to test the Factory pipeline (ba-ticket -> factory-init -> factory). Tasks are kept in the browser; there is no server.

## Run

```sh
pnpm install
pnpm dev          # http://localhost:5173
```

## Checks

```sh
pnpm lint && pnpm format && pnpm typecheck && pnpm test && pnpm build
```
